02 · Granulation

Every measurement becomes three fuzzy ideas

Each scaled feature is described as low, medium and high by overlapping triangles. Drag the marker, or load a real patient, and watch the 32-number input vector change. The overlap is one of the five things the swarm tunes.

The network's input

8 crisp values + 24 granule memberships. Tap a row to inspect that feature.

03 · Live tuning

Watch two swarms search

Two particle swarms start from the identical random population and hunt for the best network settings, scored by 3-fold cross-validation on the 614 training patients. One keeps a fixed inertia weight. The other adapts it to swarm diversity. They run in parallel, right here.

Best cross-validated accuracy so far

Higher is better. Each point is one swarm iteration.

Held-out test results

Each model is retrained as a 5-seed ensemble on the training split, then scored once on the 154 patients it never saw. The manual model is a hand-picked reference trained at page load.

This is a JavaScript port of the Python pipeline: same architecture, preprocessing, split seed and PSO equations. Live numbers will drift a little from the scikit-learn numbers in the report, and they move with the seed. That variation is the point of testing more than one run.
